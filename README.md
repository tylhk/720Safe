# 720安全大王

一款 Windows 电脑清理加速软件：桌面悬浮球实时显示内存和 CPU 占用，一键清理内存、垃圾文件，管理开机启动项，并在 C 盘空间不足或电脑卡顿时提醒和记录。

## 运行环境

Windows 10 / 11，需安装 [.NET 9 桌面运行时](https://dotnet.microsoft.com/download/dotnet/9.0)（.NET Desktop Runtime 9）。

## 编译

```powershell
.\build.ps1
```

生成的程序在 `src\Safe720\bin\Debug\net9.0-windows\Safe720.exe`，双击运行。

## 使用方法

悬浮球默认在屏幕右下角，液面高度是内存占用，外圈是 CPU 占用。

- **单击**：一键加速（清理内存）
- **拖动**：按住左键拖到任意位置
- **鼠标悬停**：查看 C 盘剩余空间和上次清理结果
- **球右上角出现红色「!」**：C 盘空间不足，右键 → 垃圾清理

**右键菜单：**

| 菜单 | 作用 |
|---|---|
| 垃圾清理… | 扫描临时文件、更新缓存、崩溃转储、浏览器缓存、回收站，勾选后清理 |
| 启动项管理… | 禁用不需要的开机自启程序，可随时恢复 |
| 清理临时文件 | 一键清理超过 24 小时的临时文件 |
| 查看卡顿日志 | 查看电脑卡顿时是哪些程序在占用资源 |
| 设置 | 开关每天自动清理、C 盘提醒、卡顿记录、置顶、开机自启 |
| 以管理员身份重启 | 获得管理员权限，清理更彻底 |
| 退出 | 关闭悬浮球 |
