# 720安全大王

一款 Windows 电脑清理加速软件：桌面悬浮球实时显示内存和 CPU 占用，一键清理内存、垃圾文件，管理开机启动项，并在 C 盘空间不足或电脑卡顿时提醒和记录。

## 运行环境

Windows 10 / 11，需安装 [.NET 9 桌面运行时](https://dotnet.microsoft.com/download/dotnet/9.0)（.NET Desktop Runtime 9）。

## 编译

```powershell
.\build.ps1
```

生成的程序在 `src\Safe720\bin\Debug\net9.0-windows\Safe720.exe`，双击运行。

编译时会同时生成发给别人用的单文件版 `publish\small\Safe720.exe`（对方需装 .NET 9 桌面运行时）。首次双击会自动安装到 `%LOCALAPPDATA%\720安全大王` 并设为开机自启，卸载运行该目录下的 `卸载.cmd`。

## 使用方法

悬浮球默认在屏幕右下角，液面高度是内存占用，外圈是 CPU 占用。

- **单击**：一键加速（清理内存）
- **双击**：弹出迷你面板（内存/CPU 仪表、C 盘、占用最高的程序、常用功能）
- **拖动**：按住左键拖到任意位置；拖到屏幕左右边缘会贴边并缩进一半，鼠标靠近自动滑出
- **拖文件夹到球上**：查看文件夹大小和里面最占空间的内容；拖文件则直接显示文件大小
- **鼠标悬停**：查看内存、CPU、C 盘剩余空间和上次清理结果
- **球右上角出现红色「!」**：C 盘空间不足，右键 → 垃圾清理 / C 盘空间分析

**右键菜单：**

| 菜单 | 作用 |
|---|---|
| 垃圾清理… | 扫描临时文件、更新缓存、崩溃转储、浏览器缓存、回收站，勾选后清理 |
| C 盘空间分析… | 扫描整个 C 盘，按文件夹逐层展开看谁最占空间，并列出最大的文件；只分析不删除 |
| 软件卸载… | 列出已安装软件，可搜索、按大小/安装时间排序，调用软件自带的卸载程序 |
| 启动项管理… | 禁用不需要的开机自启程序，可随时恢复 |
| 高占用程序… | 按 CPU / 内存 / 磁盘列出最占资源的程序，可一键结束；也能查看卡顿日志 |
| 清理临时文件 | 一键清理超过 24 小时的临时文件 |
| 迷你面板 | 同双击 |
| 设置… | 显示悬浮球、置顶、贴边、全屏自动隐藏、开机自启、每天自动清理、C 盘提醒、卡顿记录与通知 |
| 隐藏悬浮球 | 只留托盘图标，单击托盘图标恢复 |
| 以管理员身份重启 | 获得管理员权限，清理更彻底 |
| 退出 | 关闭悬浮球 |

**托盘图标：** 数字是内存占用，颜色与液面一致；悬停看内存、CPU；单击显示/隐藏悬浮球；右键菜单与悬浮球相同。

**其他：** 看视频、玩游戏、放映等全屏时悬浮球自动隐藏，退出全屏后恢复；程序只会运行一个，重复打开会把已有的悬浮球叫出来；高占用程序里 dotnet、python、java 等宿主进程按实际运行的脚本分开显示、单独结束。

**卡顿通知：** CPU、内存或磁盘持续 10 秒满负荷时，右下角弹出通知，写明占用最高的程序，点开即可结束它（10 分钟内最多提醒一次，可在设置中关闭）。
